PrintHero Uninstaller
====================

This folder contains the PrintHero uninstaller utility.

To completely remove PrintHero from your system:
1. Close PrintHero if it's running
2. Right-click PrintHero.Uninstaller.exe and select "Run as Administrator"
3. Follow the uninstaller prompts

The uninstaller will:
- Stop and remove the PrintHero service
- Remove all installed files
- Remove registry entries
- Remove desktop and start menu shortcuts
- Remove auto-startup entries

Note: User configuration files may be preserved for future installations.
